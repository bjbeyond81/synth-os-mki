# SYNTH_OS // MKI — Improved Human Edge Edition

Boutique web groovebox / 16-step sequencer.

### Fixed & Improved
- Audio chains for snare, hihat and bass correctly routed through GainNodes
- Dynamic AI analysis + Soul Score based on pattern density and human anchors (kick on 1, snare on 2/4)
- Randomize keeps the kick on the downbeat (human edge constraint)
- Cleaner recording flow
- Tailwind + Lucide properly set up

### Run
```bash
npm install
npm run dev
```

Built with React + Web Audio API. No external audio libraries.
